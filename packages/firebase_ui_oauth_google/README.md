# Firebase UI OAuth Google


## Migrating from `firebase_ui_oauth_google`

See [Migrating from upstream Firebase UI](https://github.com/gnomezgrave/forui_FirebaseUI-Flutter#migrating-from-upstream-firebase-ui) in the repository README (`firebase_ui_*` → `forui_firebase_ui_*`).

## Getting Started

To get started with Firebase UI OAuth Google, please [see the documentation](../../docs/firebase-ui-auth/providers/oauth.md#google-sign-in). Apps must wrap Firebase UI in an [`FTheme`](https://forui.dev/docs) ancestor.
