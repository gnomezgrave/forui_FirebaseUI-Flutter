# Firebase UI for Realtime Database

Firebase UI widgets for Realtime Database, ported to [Forui](https://forui.dev). Requires an `FTheme` ancestor and Flutter **3.47+**. `FirebaseDatabaseDataTable` remains Material-based.

## Platform support

Follows [FlutterFire Realtime Database](https://github.com/firebase/flutterfire#stable-plugins) (Android, iOS, Web, macOS beta). Windows and Linux are not supported.

## Migrating from `firebase_ui_database`

See [Migrating from upstream Firebase UI](https://github.com/gnomezgrave/forui_FirebaseUI-Flutter#migrating-from-upstream-firebase-ui) in the repository README (`firebase_ui_*` → `forui_firebase_ui_*`).

## Getting Started

See the [documentation](../../docs/firebase-ui-database.md).

```sh
flutter pub add firebase_database forui_firebase_ui_database forui
```
